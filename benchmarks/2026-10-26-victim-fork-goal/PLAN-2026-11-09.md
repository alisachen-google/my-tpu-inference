## Common setup

- Software: main-pinned venv (`~/venv/sglang-main`, `tpu-sync-torch==0.0.1.dev20261103081657`), the PR tree deployed with
  `harness/goal/deploy_1992.sh <ip> <tree>` to **every** host of a stage before any engine starts (a mixed-tree pair stalls
  requests instead of failing: issue I11).
- Hosts: g = geyuhao-v7-8 (10.128.0.175, prefill), v7 = 10.128.15.239 (decode), amandaliang-v7x-8 (10.128.0.246), the
  amandaliang-v7x-16 workers (10.128.1.42 / .99, busy with another job), a / b (wyzhang-tpu7x-16, wedged at TPU start).
- Engines: TP8 per role, fp8 KV, 128k-token sessions + 8k new tokens, `--hicache-write-policy write_back` on both roles
  (write-through where stated), decode radix cache on, caches flushed before every point (`WIPE CHECK` must read 0/0).
- Metrics: **prefill-side hit** = the prefill's `cached_tokens_total` delta over the point window, cross-checked with the sum
  of `#cached-token` in its batch log (the client-side `cached_tokens` is inflated by the decode's own radix cache when the
  switch is off); TTFT p50 of the recall-phase requests; request errors by `strict.py` (a request without completion tokens
  counts as failed); engine health by `Scheduler hit an exception|out of memory` counts in both server logs (balancer
  connection errors are not engine exceptions). Transfer evidence from `evidence.sh` (pushes stored/landed, offers, pulls,
  skipped/no-memory/over-budget/failed, adopted backup tokens).
- Switch: `SGLANG_ENABLE_PREFILL_KV_OFFLOAD_TO_DECODE_DRAM=1` on both roles; "off" = the same tree with it unset.

refused by name; a tpu-sync build without the host read API refused by name (unit).

## Harness

Stage scripts in `harness/goal/` (`goal_fix_validate.sh`, `goal_hybrid_full.sh`, `goal_unsupported.sh`, `goal_2p1d_x2b.sh`,
`goal_2p2d_wait_nowait.sh`, `edges.sh`, `evidence.sh`, `strict.py`, `compare_layouts.py`, `prefill_hit_window.py`), run log in

one tree on all hosts of a stage; set `EDGE_A`/`EDGE_V` and `PIP`/`DIP` for the edge and evidence scripts; delete a run's
result files before a rerun with the same name; wait for the previous pair's TPU devices and control ports to be released
before starting the next (teardown race, issues I1 and I14).
